# بوابة الخدمات الرقمية

واجهة عربية مستقلة مستوحاة من هيكل بوابات الخدمات: عنوان، ترحيب، وبطاقات خدمات. لا تتضمن أي نموذج لجمع بيانات مالية أو اعتماد بنكي.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## النشر على Vercel

1. ارفع المشروع إلى مستودع GitHub جديد.
2. افتح https://vercel.com/new واربط حساب GitHub.
3. اختر المستودع ثم Deploy؛ سيتعرف Vercel تلقائياً على Next.js.

لتعديل الاسم والخدمات عدّل `app/page.jsx`، وللألوان والتنسيق عدّل `app/globals.css`.
