# بوابة الخدمات الرقمية — Demo

مشروع Next.js جاهز للنشر على Vercel بهوية تجريبية مستقلة. لا يرتبط بأي بنك، ولا يطلب بيانات بنكية أو تسجيل دخول.

## النشر

ارفع **المحتويات الموجودة داخل هذا المجلد** إلى جذر مستودع GitHub. يجب أن يظهر مجلد `app` بجوار `package.json` في جذر المستودع. من Vercel اختر Import Repository ثم Deploy؛ إطار العمل Next.js.

## التشغيل محليًا

```bash
npm install
npm run dev
```
